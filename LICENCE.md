## 🧩 About

**Warcraft 3 helpers** is a curated list of Warcraft 3 open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource viewer, camera control
- **Quality-of-Life Helpers** — custom hotkeys, unit info, overlay notes
- **Research Notes** — map layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Game Helpers
- Resource Viewer — track gold, lumber, and supply
- Show Unit Info — visualize health, mana, and abilities
- Replay Notes — record and review match runs
- Game Speed — adjust game speed for study (0.5x to 2x)

### 🗺️ Map & UI
- Map Explorer — browse map layouts and creep camps
- Custom UI Notes — organize interface elements
- Camera Control — zoom and lock camera for study

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map
- Hero Control — manually switch hero abilities
- Build Order Notes — plan and review strategies
